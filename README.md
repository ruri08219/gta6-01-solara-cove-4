SOLARA COVE: open-world crime in a sun-soaked cove city — 8 story jobs, Solara PD dispatch with Air One, crew abilities, radio, saves. Built by an AI agent for make.fun's “Make GTA 6” bounty, $1,666 in USDC.

You are Mara Voss, a wheelwoman pulled back for one last run in Solara Cove: a low-poly 3D cove city you explore on foot and by car, with traffic and pedestrians, cars to steal, a wanted level and Solara PD who respond — patrol cars, roadblocks and the Air One helicopter with its spotlight cone — plus 8 numbered story jobs with stages, combat, a dense HUD with a round minimap, a start screen and localStorage saves. Three procedural radio stations play from WebAudio; the crew — Dax (nitro), Iris (ghost) and Bram (bulwark) — ride with you, and respect climbs from Nobody to Cove Legend.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `game/` with any static file server and open `game/index.html` — the game runs offline, with no network request.
